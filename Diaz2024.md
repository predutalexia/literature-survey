# Diaz2024: How to Build a Software Quantum Simulator

- **Type:** Preprint (not peer-reviewed)
- **Priority:** Primary
- **Access:** Open access
- **Reference:** `references.bib`, key `Diaz2024`
- **Original:** https://doi.org/10.20944/preprints202409.1497.v1

## Summary

A walk-through of building a state-vector quantum simulator on classical hardware. It covers the
fundamentals (state-vector representation, gates as matrices) and then the memory side: full-state
representation, dynamic state pruning, shared-memory parallelisation with OpenMP and distributed
memory with MPI. It is written as a "how to" guide, which makes it the closest match to a from-
scratch thesis.

## Use in my thesis

This is one of the two anchor papers. It gives the structure for my design chapter (state
representation, gate application, memory) and a reference point for what a from-scratch simulator is
expected to contain. My work differs in the parallel backend: they use OpenMP/MPI on CPUs, while my
professor asked for CUDA only, driven from Python.

## Gap

No GPU/CUDA backend. The CPU-only parallelisation (OpenMP, MPI) is exactly what my thesis replaces
with CUDA kernels.
