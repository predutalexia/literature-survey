# Diaz2025: Memory Management Strategies for Software Quantum Simulators

- **Type:** Journal article
- **Priority:** Primary
- **Access:** Open access (CC BY 4.0)
- **Reference:** `references.bib`, key `Diaz2025`
- **Original:** https://doi.org/10.3390/quantum7030041

## Summary

Peer-reviewed continuation of Diaz2024 by the same group, published September 2025. It studies and
evaluates memory-management strategies for scaling state-vector simulation on classical machines.

## Use in my thesis

Citable, peer-reviewed version of the Diaz2024 ideas. Use it when I justify memory limits (a 2^n
complex vector must fit in GPU memory) and when I explain why I stay with a full state vector.

## Gap

Focus is memory on CPU systems; no CUDA implementation.
